# smtengowebsite — agent must-knows

Public website for enGo (智管家科技). Vue 3 + Vite + TypeScript, vue-i18n (7 locales), Vercel serverless
functions in `api/` backed by Supabase. Read `DESIGN.md` before any UI work and `DEPLOYMENT.md` before any
deploy/env work. zh-TW first for anything a Taiwanese visitor reads.

## The one rule that causes damage

**`main` auto-deploys to PRODUCTION (www.smtengo.com) on Vercel.** Every other branch/PR gets a preview URL.
Never push to `main`. Branch → PR → Vercel preview → Sean merges. A merge *is* a prod deploy.

## Commands (gates run locally before every PR; CI runs the same)

```bash
npm ci                                   # Node 24 (matches Vercel); local 22 works too
npm run type-check                       # vue-tsc --build --force
npx vitest run                           # 19 files / 367 tests incl. locale parity, SEO parity, design tells, legal register
npm run lint:ci                          # eslint, errors only block
node scripts/legal-register.mjs check    # controlled-document stamps + hashes (also inside vitest)
npm run dev                              # vite on :5173
```
`npm run lint:ci` (no `--fix`) is a gate: **errors block, warnings don't**. `npm run lint` autofixes locally. Config is
`.eslintrc.cjs` (create-vue standard; `video/` and `public/` ignored). Prefer fixing an `@typescript-eslint/no-unused-vars`
warning over silencing it.
`npm run build` = type-check + `vite build` + `postbuild` prerender-meta; Vercel runs it on every PR, so CI does
not duplicate the build.

## Layout

| Path | What |
|---|---|
| `src/views/*.vue`, `src/components/` | pages and components; routes mirror `vercel.json` rewrites (`/product`, `/cases`, `/en/...`) |
| `src/locale/{zh,zhCN,en,ja,fr,es}.ts` | vue-i18n messages. `zh` is the source of truth; `localeParity.test.ts` guards structure |
| `src/data/*.json` | content: cases, faqs, knowledge_base, howto, news, `legal.json` |
| `public/<doc>.html` | **controlled legal documents** (terms / privacy / return-policy, currently rev A.2) |
| `api/` | Vercel functions: contact, chatbot-query, legal/acknowledge, line/webhook, admin/* — the only place secrets are read |
| `lib/` | server helpers (supabase-admin, session) |
| `scripts/` | `legal-register.mjs`, `gen-knowledge-md.mjs`, `gen-manual-index.mjs`, `google-pull.mjs`, `prerender-meta.mjs` |
| `docs/LEGAL_DOCUMENT_REGISTER.md` | generated by `legal:register` — never hand-edit |
| `supabase_*.sql` | schema for the Supabase project `website` (Tokyo) |

## Rules

1. **Legal pages are controlled documents** (ISO 27001 7.5). Any change to `public/terms*.html`, `privacy*.html`,
   `return-policy*.html` must go through `node scripts/legal-register.mjs bump <id> <A.n> "<change>"`, or the test
   suite fails. Wording changes are 法務 work: route through `tom-legal`, keep `[待律師確認]` until cleared.
2. **Every locale or none.** A new UI string lands in all seven `src/locale/*.ts` files. If you cannot translate
   one, keep the English fallback with `// TODO: translate` and list it in the PR. Known debt vs `zh`
   (2026-11-10): `en` −47 keys, `ja` −35, `es`/`fr` −114.
   ⚑ D:5/CHINA FLAG: `zhCN.ts` is a PRC-facing locale — flag work on it per company policy.
3. **Truth gate on public copy.** Never invent a product capability. Verify against `~/Claude_File/enGo_app/docs`
   (ENGO-WEB-001 / ENGO-KB-001) or mark `[待確認]`. Screenshots are never retouched.
4. **Generated files are regenerated, not edited:** knowledge markdown (`gen:knowledge` → feeds Shop's knowledge
   API), manual index (`gen:manuals`), legal register, prerendered meta.
5. **Secrets live in Vercel project settings only.** `vercel env pull` returns sensitive vars as *empty* (CLI
   refusing to decrypt, not an empty value). Browser bundle contains no keys. Never paste a secret into chat;
   report name + length only.
6. **SEO parity:** runtime `seo.*` titles/descriptions must match the prerendered shells (`seoParity.test.ts`,
   `seoTitles.test.ts`). Structured data via `schema` skill; AI-search visibility via `ai-seo`.
7. **Design authority:** the brief → `DESIGN.md` → skill taste. `designTells.test.ts` fails on AI-slop patterns in
   content files.
8. **Prove UI in a browser:** screenshots at 1280 and 390 from the Vercel preview, console clean, Lighthouse
   numbers quoted in the PR.
